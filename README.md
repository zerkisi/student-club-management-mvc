\# CampusHub - ASP.NET Core MVC Student Club Management System



CampusHub is a responsive ASP.NET Core MVC web application developed for managing university student clubs, activities and student registrations.



\## Features



\- ASP.NET Core MVC Architecture

\- Responsive Bootstrap 5 Design

\- Student Registration Form

\- Student Search System

\- Club Detail Modals

\- Activity Registration Modals

\- Dashboard Homepage

\- Multi-Page MVC Structure

\- Image Based Activity Cards

\- JavaScript Form Validation



\## Technologies Used



\- ASP.NET Core MVC

\- C#

\- HTML5

\- CSS3

\- Bootstrap 5

\- JavaScript



\## Project Pages



\- Home

\- Clubs

\- Students

\- Activities

\- Register
